# 每日基础技术总结 · 2026-06-28 · LL(1) 预测分析表与 FIRST/FOLLOW 集

## 📚 今日主题

> **LL(1) 预测分析表与 FIRST/FOLLOW 集**（算法与数据结构）

### 1. 核心概念速览
LL(1) 预测分析表是自顶向下语法分析器的核心驱动结构，它根据当前输入符号（lookahead）与栈顶非终结符，唯一确定应采用的产生式。其本质是文法在‘单符号前瞻、最左推导’约束下的确定化函数：M[N, T] → 产生式 ∪ error。FIRST/FOLLOW 集是构造该表的静态信息基础：FIRST(α) 是从 α 能推导出的所有终结符首符集合（含 ε 当且仅当 α ⇒* ε）；FOLLOW(A) 是在所有句型中可能紧跟在非终结符 A 之后的终结符集合（含 $ 作为输入结束符）。LL(1) 的本质条件是对同一非终结符的任意两条产生式 A → α | β，要求 FIRST(α) 与 FIRST(β) 不相交，且若 α ⇒* ε，则 FIRST(β) ∩ FOLLOW(A) 为空。该条件保证查表时每个表项至多一个产生式，从而消除回溯，实现线性时间解析。在整个计算机体系中，预测分析是编译原理前端的核心环节，也是递归下降解析器自动化的基础；同时，FIRST/FOLLOW 的计算思想广泛用于自然语言处理中的语法分析、代码生成中的文法验证，以及各类‘基于前瞻做决策’的算法设计。专业工程师必须掌握它，因为它是理解语法分析器生成器（如 ANTLR、Yacc）内部机制、设计无歧义语法、排查解析冲突的底层理论基础，也是从‘会调解析库’进阶到‘能实现解析器’的分水岭。

### 2. 底层原理剖析
底层运行机制分为三个层次：

1. 计算 FIRST 集（不动点迭代）：
   - 对每个文法符号 X，初始化 FIRST(X) = ∅。
   - 应用规则直到集合不再增长：
     a. 若 X 是终结符，FIRST(X) = {X}。
     b. 若 X → ε，则 ε ∈ FIRST(X)。
     c. 若 X → Y1 Y2 ... Yk，则从左向右扫描：将 FIRST(Yi) 中除 ε 外所有符号加入 FIRST(X)；若 FIRST(Yi) 含 ε，继续处理 Yi+1；若所有 Y1..Yk 均含 ε，则将 ε 加入 FIRST(X)。
   - 对于符号串 α = X1 X2 ... Xm，FIRST(α) 同样规则：依次取 FIRST(Xi) 的非 ε 元素，直到遇到不含 ε 的 Xi 为止；若所有 Xi 均可为 ε，则 ε ∈ FIRST(α)。

2. 计算 FOLLOW 集（不动点迭代）：
   - 初始化：FOLLOW(S) = {$}（S 为开始符号），其余 FOLLOW(A) = ∅。
   - 应用规则直到不再变化：
     a. 对产生式 A → α B β，将 FIRST(β) 中除 ε 外所有符号加入 FOLLOW(B)。
     b. 若 A → α B 或 A → α B β 且 β ⇒* ε，则将 FOLLOW(A) 中所有符号加入 FOLLOW(B)。
   - 注意 FOLLOW 集中永不含 ε。

3. 构造预测分析表 M[N, T]：
   - 对每个产生式 A → α，执行：
     a. 对每个终结符 a ∈ FIRST(α)，将 A → α 填入 M[A, a]。
     b. 若 ε ∈ FIRST(α)，则对每个 b ∈ FOLLOW(A)，将 A → α 填入 M[A, b]；若 $ ∈ FOLLOW(A)，也填入 M[A, $]。
   - 若某表项已有产生式，则发生冲突，文法不是 LL(1)。

4. 预测分析执行机制：
   - 栈初始为 [$, S]，输入串后追加 $。
   - 每次看栈顶符号 X 与当前输入符号 a：
     - 若 X 是终结符，则 X 必须等于 a，弹出 X，输入指针前移；否则报错。
     - 若 X 是非终结符，查 M[X, a]；若无定义则报错；若有产生式 X → Y1...Yk，弹出 X，将 Yk...Y1 逆序压栈（若 α=ε 则什么都不压）。
     - 若 X=$ 且 a=$，则接受。

与前端已有概念的对比：预测分析表本质是一个二维的‘决策路由表’，类似前端中事件委托的映射表（selector → handler），但这里的确定性由文法的 LL(1) 条件保证；FIRST/FOLLOW 集类似于 TypeScript 的类型收窄所需的‘可能输入集合’，但它们是语法层面静态计算的闭包；LL(1) 的‘无回溯’机制类似于 React 的 reconcile 过程中通过 key 做确定性匹配，一旦 key 冲突就会渲染异常，对应文法冲突。此外，递归下降解析器中的每个函数对应一个非终结符，函数体内的分支判断就是在手工模拟查询 FIRST/FOLLOW 集，而预测分析表则是将这种逻辑显式数据化，二者本质等价。

### 3. 基础代码与实战验证
以下为极简的 LL(1) 表构造与预测分析过程的文字化伪代码（不依赖具体语言）：

```
// 文法：
// E  → T E'
// E' → + T E' | ε
// T  → F T'
// T' → * F T' | ε
// F  → ( E ) | id

// 步骤1：计算 FIRST 集（不动点）
FIRST(F)  = { ( , id }
FIRST(T') = { * , ε }
FIRST(T)  = { ( , id }
FIRST(E') = { + , ε }
FIRST(E)  = { ( , id }

// 步骤2：计算 FOLLOW 集（不动点）
FOLLOW(E) = { $ , ) }
FOLLOW(E') = { $ , ) }
FOLLOW(T) = { + , $ , ) }
FOLLOW(T') = { + , $ , ) }
FOLLOW(F) = { * , + , $ , ) }

// 步骤3：构造预测分析表 M
// 对 E → T E'：FIRST(T E') = { ( , id }，故 M[E, (] = E→T E'，M[E, id] = E→T E'
// 对 E' → + T E'：FIRST(+ T E') = { + }，故 M[E', +] = E'→+ T E'
// 对 E' → ε：ε ∈ FIRST(ε)，故对 b ∈ FOLLOW(E')={$,)}，填 M[E', $] = E'→ε，M[E', )] = E'→ε
// 对 T → F T'：FIRST(F T') = { ( , id }，故 M[T, (] = T→F T'，M[T, id] = T→F T'
// 对 T' → * F T'：M[T', *] = T'→* F T'
// 对 T' → ε：对 b ∈ FOLLOW(T')={+,$,)}，填 M[T', +] = T'→ε，M[T', $] = T'→ε，M[T', )] = T'→ε
// 对 F → ( E )：M[F, (] = F→( E )
// 对 F → id：M[F, id] = F→id
// 其余表项为 error

// 步骤4：预测分析过程（输入串 id + id * id）
// 栈初始: [$, E]  输入: id + id * id $
// 1. 栈顶 E，输入 id：查 M[E, id] = E→T E'，弹出 E，压入 E' T（逆序），栈变为 [$, E', T]
// 2. 栈顶 T，输入 id：查 M[T, id] = T→F T'，弹出 T，压入 T' F，栈变为 [$, E', T', F]
// 3. 栈顶 F，输入 id：查 M[F, id] = F→id，弹出 F，压入 id，栈变为 [$, E', T', id]
// 4. 栈顶 id，输入 id：匹配，弹出 id，输入指针移到 +，栈变为 [$, E', T']
// 5. 栈顶 T'，输入 +：查 M[T', +] = T'→ε，弹出 T'，不压入，栈变为 [$, E']
// 6. 栈顶 E'，输入 +：查 M[E', +] = E'→+ T E'，弹出 E'，压入 E' T +，栈变为 [$, E', T, +]
// 7. 栈顶 +，输入 +：匹配，弹出 +，输入指针移到 id，栈变为 [$, E', T]
// 8. 后续同理，最终栈和输入均为 $，接受。
```

关键注释：预测分析表中每个表项就是‘当非终结符遇到某个终结符时，唯一应采用的产生式’。栈中压入产生式右部逆序是为了让栈顶保持最左待推导符号，符合最左推导顺序。ε 产生式的处理不是‘压入空’，而是‘什么都不压’，这等价于当前非终结符推导为空串，并依赖 FOLLOW 集决定该产生式适用的输入符号。

### 4. 常见误区与进阶思考
常见误区：

1. 误以为 FIRST 集和 FOLLOW 集只用于构造 LL(1) 表，而忽略它们是自顶向下分析‘预测信息’的完整抽象。实际工程中，即使不显式建表，递归下降解析器中的每个分支判断都在隐式计算并利用 FIRST/FOLLOW 信息；不理解这一点，就无法在手工编写解析器时处理左递归和公共前缀，也无法理解为何 LL(1) 文法不能有左递归。

2. 将 FOLLOW 集与‘某个符号之后可能出现的所有符号’混淆。FOLLOW 只针对非终结符，且不包含 ε；而 FIRST 可以针对任意符号串。另一个常见错误是计算 FOLLOW 时忽略‘产生式右部末尾非终结符’的情况：A → α B 时，FOLLOW(B) 必须包含 FOLLOW(A)，这本质是‘B 后面的东西就是 A 后面的东西’，因为 B 可以推导到整个 A 的末尾。

深度思考题：给定文法 S → A a | b，A → c | ε。该文法是 LL(1) 吗？请通过构造 FIRST/FOLLOW 集并检查 LL(1) 条件给出判断；如果不满足，请指出具体冲突的表项，并思考能否通过提取公共因子将其改写为等价的 LL(1) 文法（注意提取后仍需验证）。这题的关键在于理解 ε 产生式与 FOLLOW 集如何导致预测表冲突，以及改写后文法的等价性边界。
