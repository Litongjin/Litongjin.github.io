# 每日基础技术总结 · 2026-09-18 · Chain-of-Thought（思维链）基础

## 📚 今日主题

> **Chain-of-Thought（思维链）基础**（AI 开发基础（LLM & Agent））

### 1. 核心概念速览
**定义**：Chain-of-Thought（CoT）指在自回归解码过程中，令模型在输出最终答案 y 之前，先生成一段中间 token 序列 z = (z₁, z₂, …, z_k)，并将 z 拼回上下文参与后续条件概率计算，即以采样近似实现

p(y | x) = Σ_z p(z | x) · p(y | x, z)

**本质**：Transformer 的单次前向传播是一个固定深度、无循环的电路——L 层串行算子依次作用，前向图深度恒为常数 L，宽度随上下文长度增长（attention），但不存在跨 token 的迭代状态。对于串行依赖深度随输入规模 n 增长的函数（多位进制运算、动态规划、图可达性、长程约束满足），固定深度电路无法在单次前向内完成。CoT 通过把中间状态外化为 token 并回灌上下文，将「深度受限的单次电路」转变为「长度可变、以离散 token 为载体的循环计算」，有效串行深度由 O(L) 变为 O(L · (k + |y|))。

**它在体系中的位置**：CoT 不属于模型结构，也不属于训练目标，而是**推理/解码层的调度策略**——它改变的是解码器每一步的输入构造方式与生成长度分配，而非权重。它是 ReAct（中间 token 插入外部动作与观测）、Self-Consistency（对同一链多次采样做边缘化）、Tree-of-Thought（把链变成带价值函数的搜索树）、以及 o1/R1 式长 CoT 强化学习的共同基元。

**为什么专业工程师必须掌握**：它把「推理算力」从训练期的一次性投入，变成推理期可按题分配的连续变量（test-time compute scaling）。这是当前 LLM 系统成本—精度曲线上最核心的杠杆：链长、采样数、验证器数量直接决定延迟、显存与准确率。不理解其机制，就无法判断何时该用、该用多长、以及何时它反而有害——这是把 LLM 当作可工程化组件而非黑箱调用的前提。

### 2. 底层原理剖析
### 1. 自回归分解与固定深度约束
自回归建模给出 p(x) = Π_t p(x_t | x_<t)。第 t 个 token 的分布由一次完整前向算出，其计算图深度恒为 L（层数），与 t 无关。因此单次前向可计算的函数类被限制在常数深度电路（宽度受 d 与 attention 精度约束）。任何需要 Ω(n) 层串行依赖的任务，都无法在单次前向中完成——这不是模型「不够聪明」，而是计算图深度不满秩。

### 2. CoT 是一次程序变换：循环展开 + 状态外化
生成 z₁…z_k 的过程等价于把迭代算法展开为直线代码，每一步的中间值被写入外部存储（token 序列），下一步以前一步的输出为条件：

z_i ~ p(· | x, z_<i)，  y ~ p(· | x, z)

有效串行深度 = L · (k + |y|)；有效算力 ≈ 生成长度 × 每步 FLOPs。代价随之出现：KV cache 随序列长度线性增长（每层每 token 缓存 2·d 个值），解码期每步 attention 成本 O(t)，总成本对长度超线性。

### 3. 离散瓶颈：每步只有 ≤ log₂|V| bit 跨边界
跨步传递的唯一载体是被采样出的 token id，理论上限为 log₂|V|（GPT-2 词表 50257 时约 15.6 bit；常见 128k 词表约 17 bit）。残差流中 d≈4096 维、bf16 精度的模拟状态在每步结束时被打包为 KV cache 被动保留，但**不可写回**为下一步新的可微状态。这构成两个直接推论：
- 链的信息承载是低带宽、离散的，与 RNN 的隐状态（连续、高带宽、可微、不可验证）形成精确对偶；
- 正因为离散，token 才可被外部程序解析、校验、分支、检索——可验证性是以带宽为代价换来的。

### 4. 与前端的同构对照
- **单次前向 ≈ 同步纯函数调用**：原子、无让出点、调用栈深度固定。前向内部的中间量类似闭包环境，运行结束即消失，外部不可观测、不可干预。
- **CoT ≈ 把同步计算改写成 generator/async 迭代**：每个 yield 必须把状态序列化到外部（token 流），恢复时再反序列化（读回上下文）。这与 SSR 必须把状态序列化为 HTML 字符串再 hydrate 完全同构——**非可序列化状态必然丢失**。这也是为什么长链会丢细节：残差流的高维状态无法全部塞进一个离散 token。
- **KV cache ≈ memoization / 闭包保留环境**：避免重复计算历史 K/V，但它是只读缓存，不是可写回的可变状态。
- **采样 + Self-Consistency ≈ 对含随机性的函数做 N 次独立运行后聚合**，是对 p(y|x) 边缘化的 Monte Carlo 近似。
- **Java 接口 vs TS 接口的对照**：Java 接口在运行期以 vtable/动态分派实体存在——可观测、可反射、有运行时代价；TS 接口在编译期被完全擦除——不可观测、零运行时代价。单次前向中的「推理」就是 TS 接口：只存在于潜在表示中，无法被外部观测或干预；CoT 把它变成 Java 接口式的运行时实体——可观测、可校验，但必须承担序列化与调度开销。

### 5. 涌现与形态族谱
CoT 是规模涌现能力：低于阈值时，模型生成的中间步骤本身不可靠，链式输出会使准确率**低于**直答。形式族谱沿四个正交维度扩展：长度（few-shot / zero-shot CoT）、外部性（ReAct 插入 action+observation，把真实世界状态引入链中）、分支（ToT：链→树 + 显式价值函数 + 回溯）、随机性（Self-Consistency）。它们共享同一基元：用 token 购买串行深度。

### 3. 基础代码与实战验证
```text
# 环境：纯 Python 3，无第三方依赖
# 验证目标：(1) CoT 用 token 换串行深度；(2) 离散瓶颈量级；(3) 链式误差传播

import random, math
from collections import Counter

# ---------- 0. 任务：对 n 个数字做串行累加 acc_i = (acc_{i-1} + d_i) % 10 ----------

# ---------- 1. 模型抽象 ----------
# forward() 一次调用 == 一次完整前向传播（L 层串行算子）。
# 真实 LLM 中它是 Transformer 堆叠；此处用局部规则表保持语义等价。
TRANS = {(a, d): (a + d) % 10 for a in range(10) for d in range(10)}  # 表大小 |V|^2=100，与 n 无关

def forward(acc, d, noise=0.0):
    nxt = TRANS[(acc, d)]
    if random.random() < noise:
        nxt = random.randrange(10)     # 模拟中间步出错（幻觉的微观来源）
    return {nxt: 1.0}                  # 返回 one-hot；真实实现是 |V| 维 logits 经 softmax

# ---------- 2. 直答式：一次前向直接输出答案 ----------
def direct_cost(n):
    return 10 ** n                     # 需要与 n 指数相关的决策表：
                                       # 等价于用固定深度电路承载 O(n) 串行依赖，不可行

# ---------- 3. CoT 解码循环：串行依赖被展开到 token 维度 ----------
def cot(digits, noise=0.0, L=32):
    acc, trace, steps = 0, [], 0
    for d in digits:
        dist = forward(acc, d, noise)  # ← 一次完整前向，计算图深度 = L
        steps += 1                     # ← 串行深度 += 1
        acc = max(dist, key=dist.get)  # ← argmax 采样：仅此离散 token 跨步传递（≤ log2|V| bit）
        trace.append(acc)              # ← 中间结果写回上下文，成为下一步的输入条件
    return acc, trace, steps * L       # 有效串行深度 = L * 生成长度

# ---------- 4. 自洽性：kh 次独立解码 + 终态多数投票 ----------
def self_consistency(digits, k=9, noise=0.0):
    votes = Counter(cot(digits, noise)[0] for _ in range(k))
    return votes.most_common(1)[0]

# ---------- 5. 量化验证 ----------
n = 8
print('direct_cost(8)  =', direct_cost(n))              # 1e8：指数爆炸
print('CoT depth       =', cot(list(range(n)))[2])      # 32*8 = 256：线性
print('bits per step   =', round(math.log2(10), 2))     # 3.32；真实词表 5e4 约 15.6

def chain_acc(n, noise, trials=5000):  # 链式结构成功率
    ok = 0
    for _ in range(trials):
        acc = 0
        for d in range(n):
            acc = max(forward(acc, d, noise), key=lambda k: 1.0)  # 每步贪心采样
        ok += (acc == sum(range(n)) % 10)
    return ok / trials

for noise in (0.0, 0.01, 0.05):
    print(noise, round(chain_acc(n, noise), 4), round((1 - 0.9 * noise) ** n, 4))
    # 实测值 ≈ 解析解：逐步正确率 p = 1 - 0.9*noise，链成功率 = p^n

# 结论：直答成本 10^n（指数），CoT 成本 256 步（线性）——串行深度被 token 买回来了；
# 但同时，误差也沿链乘积化放大：noise=0.05、n=8 时成功率已降至约 66%。
# 因此 Self-Consistency 只在「错误独立于输出层」时有效；对严格串行链，
# 多数链分享同一个早期错误，投票无法修复——这正是需要逐步验证器或 RL 训练长链的原因。
```

### 4. 常见误区与进阶思考
### 误区 1：把 CoT 输出当作模型内部计算的忠实记录（faithfulness 幻觉）
机制上，z 是被**采样出来的新 token**，它作为条件参与后续分布计算，而不是对隐藏状态的转储。模型完全可以在 token 层面生成一套与真实决策依据无关的「理由」——后续分布只受 z 的语义影响，不受「z 是否真实反映了前一步的决策过程」约束。因此：
- 禁止把 CoT 自然语言文本当结构化数据解析、做审计日志或直接作为奖励信号；需要机器消费时必须走结构化输出（JSON Schema / tool call），把「推理」与「结果」解耦；
- 高准确率不蕴含高可解释性。可解释性必须来自外部验证器（单元测试、符号求解器、约束检查），而非模型自述。

### 误区 2：认为 CoT 是无条件正收益，且与 ReAct / ToT 是同一种东西
- CoT 是**规模涌现**能力：小模型上生成的中间步骤不可靠，链式输出会让准确率低于直答；
- 对单步模式匹配类任务（简单检索、分类、格式转换），CoT 只增加延迟与噪声；
- 链越长，逐步错误率按乘积放大（见上文实测 p^n），KV cache 与 attention 开销使成本对长度超线性，存在明确的成本—精度拐点；
- 概念边界：CoT 规定的是**中间 token 的形态**；ReAct 在中间 token 中插入 action 与 observation，引入上下文之外的真实世界状态；ToT 把链变成树，引入显式价值函数与搜索回溯；Self-Consistency 在链上做多次采样求边缘化。四者是同一基元（用 token 买串行深度）在**长度、外部性、分支、随机性**四个正交维度上的扩展，不能互相替代。

### 思考题
每步跨边界只有 ≤ log₂|V| ≈ 17 bit 的离散带宽，而残差流每步持有约 d×16 ≈ 6.5×10⁴ bit 的连续状态被丢弃（仅以只读 KV cache 形式残留、不可写回）。那么「连续思维链」（直接把 hidden state 回灌作为下一步输入）在理论上能获得什么、又必然失去什么？请从三个维度论证：(a) 可验证性与可分支性（外部程序能否解析、校验、回溯）；(b) 每步信息带宽与状态压缩率对长链保真度的影响；(c) 与外部世界（工具调用、编译器、检索、人工干预点）的接口能力。并进一步回答：为什么在带宽如此受限的情况下，当前工业界仍然选择离散 token 而非连续隐状态作为推理载体？
