# 每日基础技术总结 · 2026-08-15 · 负载均衡的 L4 与 L7 区别

## 📚 今日主题

> **负载均衡的 L4 与 L7 区别**（网络基础）

### 1. 核心概念速览
L4 与 L7 负载均衡是网络协议栈不同层级上的流量分发机制。L4（传输层）工作在 OSI 第四层，基于 TCP/UDP 报文头部（五元组：源 IP、源端口、目的 IP、目的端口、协议号）做决策，不解析应用层负载，本质是一个高性能的 NAT/转发器；L7（应用层）工作在第七层，能够解析 HTTP/HTTPS/gRPC 等应用协议内容（URL、Header、Cookie、消息体），本质是一个应用层代理（Reverse Proxy）。它们解决的核心问题是：将海量并发连接映射到有限后端实例，同时保证一致性、可用性和可扩展性。L4 解决『连接级』调度，L7 解决『请求级』路由。在系统架构中，L4 是网络入口的流量闸门，L7 是业务流量的智能路由枢纽。专业工程师必须掌握二者区别，因为选型直接决定系统能处理的 QPS、延迟、故障隔离粒度、安全策略（TLS 终止、WAF）以及可观测性（URL 维度监控）的实现方式，也是设计微服务网关、Service Mesh、CDN 和 API Gateway 的理论基石。
