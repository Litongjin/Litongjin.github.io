# 每日基础技术总结 · 2025-02-02 · 双指针：快慢指针与左右夹逼

## 📚 今日主题

> **双指针：快慢指针与左右夹逼**（算法与数据结构（面试））

### 1. 核心概念速览
双指针是数组/链表遍历的空间优化技巧，本质是通过维护两个索引变量的相对运动规律，将线性扫描的 O(N^2) 复杂度降为 O(N)。快慢指针通过不同速率移动（如 Floyd 判圈算法）检测循环或定位中间节点；左右夹逼（对撞指针）利用有序性或对称性边界条件，在查找特定配对时消除无效搜索空间。该算法模式不依赖额外数据结构，属于原地算法（In-place），在数据库索引二分、图像压缩及图论路径查找中具有底层实现意义。工程师需掌握其以解决内存受限场景下的高频数据检索问题。

### 2. 底层原理剖析
核心机制在于状态空间的单调缩减。

1. 快慢指针（Fast-Slow）:
   - 机制：设 fast = n * slow (n >= 2)，若存在环，fast 必然追上 slow；若无环，fast 先触界。
   - 数学依据：在模 N 的循环群中，速度差为常数的两个元素必相遇。
   - 前端映射：类似 React useEffect 中的 cleanup 机制与 effect 执行的生命周期差异，用于追踪对象状态的突变点，但此处是确定性追踪而非异步副作用。

2. 左右夹逼（Two Pointers from Ends）:
   - 机制：适用于已排序或满足单向单调性的区间。left 向右，right 向左。
   - 决策逻辑：基于目标值 T 与当前 sum(nums[left] + nums[right]) 的关系，决定收缩哪一侧。由于数组有序，排除一侧的所有组合均为无效解，从而保证 O(N) 时间复杂度。
   - 前端映射：类似于 CSS Flexbox 中 space-between 布局下的极端元素对齐，或者 TypeScript 类型守卫中的范围收窄（Refinement），通过不断缩小可选范围逼近唯一解。

### 3. 基础代码与实战验证
```text
// 示例：有序数组的两数之和 (左右夹逼)
// 假设输入 sortedArr 为升序排列
function twoSum(sortedArr, target) {
  let left = 0;
  let right = sortedArr.length - 1;

  while (left < right) {
    const currentSum = sortedArr[left] + sortedArr[right];
    
    // 底层逻辑：利用单调性剪枝
    // 若和过大，减小较大者(right--)；若和过小，增大较小者(left++)
    if (currentSum === target) {
      return [left, right]; // 找到精确匹配
    } else if (currentSum < target) {
      left++; // 排除左侧所有较小的组合，因为它们与任何右侧元素的和仍小于 target
    } else {
      right--; // 排除右侧所有较大的组合
    }
  }
  return [-1, -1]; // 无解
}
```

### 4. 常见误区与进阶思考
误区：忽略前置条件。左右夹逼严格依赖数据的‘单调性’或‘有序性’。若在无序数组上直接应用此策略，会导致漏掉正确解（因为无法保证移除一侧元素后不会遗漏潜在组合）。

进阶思考题：
如果要求寻找的是三个数之和等于 0，且返回所有不重复的三元组，如何结合快慢指针或排序后的左右夹逼思想，在 O(N^2) 时间内解决？请描述第一层循环固定一个数后，剩余两部分的处理逻辑及其去重机制的底层原理。
