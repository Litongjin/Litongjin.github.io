# 每日基础技术总结 · 2026-08-29 · JavaScript 垃圾回收机制

## 📚 今日主题

> **JavaScript 垃圾回收机制**（前端底层与计算机基础）

### 1. 核心概念速览
JavaScript 垃圾回收（Garbage Collection, GC）是 JavaScript 引擎（V8、SpiderMonkey、JavaScriptCore 等）自动管理堆内存生命周期的机制，核心目标是确定并回收程序中不可达对象所占用的内存，防止内存泄漏并提高内存复用率。其本质是：在运行时维护对象引用关系图，周期性或按触发条件从一组根对象（Roots：全局对象、当前调用栈中的局部变量与参数、激活的闭包变量、微任务队列等）出发，遍历可达性路径，标记所有可触达对象，其余对象判定为垃圾并回收。该机制是动态类型语言语言规范层的自动内存管理方案，区别于 C/C++ 手动 malloc/free、Rust 所有权系统以及 Java/.NET 的分代 GC 理论。专业工程师必须掌握它的原因在于：虽然开发者不直接调 GC，但 GC 行为直接影响性能（卡顿、吞吐）、内存占用上限，且闭包、事件监听、缓存、WeakMap 等模式的正确性深度依赖对可达性和引用模型的理解，否则无法解释常见内存泄漏和性能问题。
