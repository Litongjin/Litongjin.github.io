# 每日基础技术总结 · 2026-06-22 · Bellman-Ford 算法的松弛轮数与负环检测

## 📚 今日主题

> **Bellman-Ford 算法的松弛轮数与负环检测**（算法与数据结构）

### 1. 核心概念速览
Bellman-Ford 算法解决带权有向图中单源最短路径问题，核心特点是允许负权边，并在无负环时保证正确。其本质是基于动态规划思想的迭代松弛：每轮对所有边执行一次松弛操作，将当前已知的最短路径长度向邻居传播。机制上，松弛操作定义为若 dist[u] + w(u,v) < dist[v]，则用更小值更新 dist[v]。算法执行至多 V-1 轮（V 为顶点数），原因是无负环时，任意最短路径至多包含 V-1 条边，第 k 轮后能确定所有至多 k 条边的最短路径。若第 V 轮仍存在可松弛的边，则说明图中存在负环——因为负环可使路径长度无限递减。在计算机体系与 AI 中，该算法是图论最短路基石，也是分布式路由协议（如距离向量算法）的理论基础，AI 中诸如概率图推断的迭代消息传递也共享类似思想。专业工程师必须掌握它，以理解在含负权网络中的路径计算边界、环检测机制，以及如何将动态规划思想映射到迭代收敛问题。

### 2. 底层原理剖析
算法维持 dist 数组，dist[v] 表示当前从源点到 v 的最短距离估计。初始化 dist[s]=0，其余为 +∞。每轮按任意顺序遍历所有有向边 (u, v, w)，执行松弛：if (dist[u] + w < dist[v]) dist[v] = dist[u] + w。松弛的本质是在已有路径上追加一条边，尝试缩短目标距离。为什么 V-1 轮足够？无负环时，设源点到某顶点的最短路径为 v0→v1→…→vk，其中 k ≤ V-1（否则路径含环，去掉正环或零环不会增加长度）。在每轮遍历所有边时，该路径上第一条边会在第 1 轮被松弛，第二条边会在第 2 轮被松弛，依此类推，因此第 k 轮后该路径终点得到正确距离。若某轮没有发生任何更新，说明所有 dist 已满足三角不等式，可提前终止。负环检测：在完成 V-1 轮后，再遍历一遍所有边，若仍存在 dist[u] + w < dist[v]，则必然存在从源点可达的负环——因为无负环时 V-1 轮已保证所有最短距离收敛，不可能再松弛；而负环能持续降低路径长度，导致第 V 轮仍可更新。注意只检测源点可达的负环，与源点不连通的负环不影响最短路。与前端已有概念的对比：类似前端中“多轮遍历直到状态不再变化”的收敛循环（如 do...while 实现稳定状态），但 Bellman-Ford 的轮次有确定上界 V-1，且每一轮对应路径边数的递推；而前端常见的收敛循环往往没有先验上界，依赖退出条件。更本质地区别是，这里松弛是图结构上的动态规划递推，而前端状态更新通常是异步的、事件驱动的，不保证在有限轮内按图拓扑传播。

### 3. 基础代码与实战验证
```text
function bellmanFord(vertexCount, edges, source) {
  const dist = new Array(vertexCount).fill(Infinity);
  dist[source] = 0;

  // 进行 V-1 轮松弛，每轮尝试用当前已知最短距离去更新所有边的终点
  for (let round = 0; round < vertexCount - 1; round++) {
    let updated = false;
    for (const [u, v, w] of edges) {
      // 松弛操作：如果源点到 u 的距离已知，且通过边 (u,v,w) 能缩短到 v 的距离
      if (dist[u] !== Infinity && dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        updated = true;
      }
    }
    // 若本轮没有任何边被更新，则已收敛，可以提前退出
    if (!updated) break;
  }

  // 第 V 轮检测负环：若还能松弛，说明存在从源点可达的负环
  let hasNegativeCycle = false;
  for (const [u, v, w] of edges) {
    if (dist[u] !== Infinity && dist[u] + w < dist[v]) {
      hasNegativeCycle = true;
      break;
    }
  }

  return { dist, hasNegativeCycle };
}

// 使用示例：
// const dist = [0, Infinity, Infinity];
// 边集：[[0,1,4],[0,2,5],[1,2,-3]] 等
// 返回 { dist, hasNegativeCycle }，dist 为最终最短距离数组
```

### 4. 常见误区与进阶思考
误区 1：认为必须严格执行满 V-1 轮，否则结果不完整。实际上，如果某一轮没有发生任何松弛，说明所有最短路径已确定，提前终止不影响正确性；但若要检测负环，不能只依赖提前终止后的状态，仍需单独执行第 V 轮全边检查。误区 2：混淆“负权边”与“负环”。负权边本身不会导致最短路无界，只要不存在负环，V-1 轮内仍能收敛；只有负环才会使最短距离不断减小，使问题无解。误区 3：在负环检测时只检查更新过的顶点或只检查部分边，必须遍历全部边，且仅当从源点可达该边时才算负环——不可达负环不会污染 dist，不应报告为负环（除非算法特意将全图初始化为 0 做全局检测）。思考题：为什么必须多执行第 V 轮来判定负环，而不是在第 V-1 轮内如果发现更新就直接判负？提示：第 V-1 轮内的更新可能恰好对应最短路径需要 V-1 条边的情况，这是合法的；而第 V 轮的更新则必然意味着存在负环，因为无负环时所有最短路径边数上界为 V-1。
