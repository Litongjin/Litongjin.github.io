# 每日基础技术总结 · 2026-05-26 · Diffie-Hellman 的素数与子群限制攻击

## 📚 今日主题

> **Diffie-Hellman 的素数与子群限制攻击**（安全基础）

### 1. 核心概念速览
Diffie-Hellman（DH）素数与子群限制攻击，又称小子群攻击或子群收敛攻击，是针对有限域 DH 密钥交换的协议级攻击。其本质是：当 DH 素数 p 满足 p-1 具有小素因子 q 时，群 Z_p^* 中存在低阶子群；攻击者可将对端公钥替换为该子群中的元素 h，使共享密钥 s=h^b 只能取 q 个可能值，从而通过枚举恢复私钥 b 对 q 的模余数。该攻击利用 DH 协议未验证公钥的群元素阶这一漏洞，是理解公钥密码学中安全参数选择（安全素数）与实现验证必要性的关键案例。专业工程师必须掌握，因为 TLS、SSH 等协议的 DH 实现若忽略子群验证，即使使用大素数也会被轻松破解。

### 2. 底层原理剖析
在有限域 DH 中，所有计算发生在乘法群 Z_p^* 中，其阶为 n=p-1。由拉格朗日定理，任意元素 g 的阶整除 n。若 n 有小因子 q，则群中存在阶为 q 的子群。攻击流程如下：
1. 攻击者截获 Alice 发送的公钥 A=g^a。
2. 攻击者构造一个阶为 q 的元素 h。常用方法是取生成元 g，计算 h=g^(n/q)，则 h^q=g^n=1，且对任意 0<k<q，h^k≠1，故 h 的阶恰为 q。
3. 攻击者将 A 替换为 h 发送给 Bob。
4. Bob 按协议计算共享密钥 s = h^b mod p。由于 h^q=1，s 仅取决于 b mod q，即 s=h^(b mod q)。
5. 攻击者枚举 i=0,...,q-1，计算 h^i，并与后续通信中观测到的加密消息或消息认证码比对，即可确定 i，从而得到 b mod q。
对多个小因子 q_i 重复攻击，得到一组同余式 b ≡ i_i (mod q_i)，使用中国剩余定理可恢复 b 模 ∏q_i。若 ∏q_i 超过 b 的取值范围，则私钥完全暴露。

防御措施分两层：
- 参数层：选择安全素数 p=2q+1，其中 q 也是素数。此时 n=p-1=2q，只有因子 2 和 q，没有其他小子群。
- 运行层：即使使用安全素数，也必须验证收到的公钥 y 满足 y^q mod p == 1 且 y≠1，以确保 y 属于阶为 q 的素数阶子群，排除阶为 1 和 2 的异常元素（如 y=-1）。

对比前端已有概念：TypeScript 的接口在编译期规定了变量形状，但运行时数据仍需实际校验，因为编译期约束在运行时可能被绕过。DH 中“选择安全素数”相当于静态架构约束，而“公钥阶验证”相当于运行时校验。二者缺一不可——静态约束缩小了攻击面，但无法覆盖每个消息的合法性；运行时验证确保每个实际到达的群元素都满足安全要求。这与前端中同时使用类型系统和运行时数据校验的思想一致。

### 3. 基础代码与实战验证
```text
import itertools

# ---- 演示小子群攻击 ----
p = 7          # 素数，p-1=6，含小因子 2 和 3
g = 3          # 生成元，阶为 p-1=6
q = 3          # 目标小因子

# Bob 的私钥
b = 5

# 攻击者构造阶为 q 的元素 h = g^((p-1)/q)
h = pow(g, (p-1)//q, p)
print('h =', h)  # h=2，阶为3

# Bob 收到被替换的公钥 h，计算共享密钥
s = pow(h, b, p)
print('Bob 的共享密钥 s =', s)

# 攻击者枚举所有 q 个可能值
for i in range(q):
    candidate = pow(h, i, p)
    if candidate == s:
        print('匹配 i =', i, '，因此 b mod q =', i)
        assert b % q == i
        break

# ---- 演示防御：验证公钥是否在素数阶子群 ----
p_safe = 11     # 安全素数，p_safe-1=10=2*5
q_safe = 5      # 大素数因子
g_safe = 4      # 生成元，阶为5
# 假设收到的公钥 y 是阶为2的元素（即 -1）
y = 10  # 10 mod 11 的阶为2
if pow(y, q_safe, p_safe) == 1 and y != 1:
    print('y 在阶 q 的子群中')
else:
    print('y 不在期望子群，拒绝')

# 注意：若 y 的阶为5，则 pow(y,5,11)=1 且 y!=1，会通过验证
y_ok = 3
if pow(y_ok, q_safe, p_safe) == 1 and y_ok != 1:
    print('y_ok 在阶 q 的子群中')
```

### 4. 常见误区与进阶思考
常见误区：
1. 认为“只要 p 足够大，DH 就安全”。实际上，大 p 只提高离散对数问题的整体复杂度，但若 p-1 含小因子，攻击者利用小子群攻击可在 O(q) 时间内泄露 b mod q，复杂度与 p 无关。例如 p 为 2048 位，但 p-1 含 32 位小因子，则 b 的模 32 位信息可被瞬间获取。
2. 认为“使用安全素数 p=2q+1 后，无需再验证公钥”。安全素数仅保证不存在除 2 以外的小因子，但攻击者仍可发送 h=-1（阶为2），使共享密钥只有两个可能值，泄露 b 的奇偶性。因此，运行时的公钥阶验证仍是必须的，这正是“静态参数安全”与“动态消息验证”的互补关系。

进阶思考题：
在安全素数 p=2q+1（q 为大素数）下，接收方收到公钥 y 后，只检查 y^q mod p == 1 且 y≠1。问：能否保证 y 的阶一定等于 q？请严格从群论中“元素的阶整除群的阶”和“q 为素数”两个条件推导，并说明如果 y 的阶为 2q 或 2，该检查为何会失败。
