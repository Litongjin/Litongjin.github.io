# 每日基础技术总结 · 2026-04-09 · 动态规划：最长公共子序列/子串

## 📚 今日主题

> **动态规划：最长公共子序列/子串**（算法与数据结构（面试））

### 1. 核心概念速览
最长公共子序列（LCS）与最长公共子串是经典的动态规划问题，旨在解决两个序列在约束条件下的最优对齐或匹配计算。

1. 最长公共子序列（Longest Common Subsequence, LCS）：要求字符在原始序列中保持相对顺序，但不必连续。本质是利用最优子结构性质，将全局最优解分解为重叠子问题的解，通常用于文本差异对比、版本控制算法（如 Git diff 的核心逻辑）、生物信息学中的序列比对。

2. 最长公共子串（Longest Common Substring）：要求字符不仅保持相对顺序，且必须在原始序列中连续出现。其状态转移逻辑与 LCS 不同，强调相邻性。

专业工程师必须掌握它，因为它是理解动态规划思想（重叠子问题 + 最优子结构）的标准范式，也是构建复杂字符串处理算法、自然语言处理（NLP）基础模型以及编译器词法/语法分析模块的理论基石。

### 2. 底层原理剖析
两者均基于动态规划表（DP Table）的状态转移机制，核心在于定义状态 dp[i][j] 的含义及推导公式。

1. LCS 机制：
   - 定义：dp[i][j] 表示 text1[0..i-1] 与 text2[0..j-1] 的最长公共子序列长度。
   - 状态转移：
     a. 若 text1[i-1] == text2[j-1]，则当前字符匹配，可由前序状态继承并加 1：dp[i][j] = dp[i-1][j-1] + 1。
     b. 若不匹配，则取不依赖当前字符的最优解：dp[i][j] = max(dp[i-1][j], dp[i][j-1])。
   - 这体现了决策树的思想：每个节点有两种分支路径，选择历史累计值最大的路径。

2. 子串机制：
   - 定义：dp[i][j] 表示以 text1[i-1] 和 text2[j-1] 结尾的最长公共子串长度。
   - 状态转移：
     a. 若 text1[i-1] == text2[j-1]，则连续长度累加：dp[i][j] = dp[i-1][j-1] + 1。
     b. 若不匹配，则连续性中断，归零：dp[i][j] = 0。
   - 最终结果为整个 DP 表中的最大值，而非右下角的单一值。

对比前端概念：这类似于 TypeScript 中的类型守卫（Type Guard）与运行时断言。LCS 关注的是“存在性”与“顺序性”的全局统计，类似于泛型约束；而子串关注的是局部上下文的严格一致性，类似于具体的接口实现验证。前端 React 的 Virtual DOM Diff 算法虽非严格 LCS，但其利用 Key 值和层次遍历优化比较的思想，底层逻辑与 LCS 的分治策略有异曲同工之妙。

### 3. 基础代码与实战验证
```text
// LCS 标准实现：空间复杂度可优化至 O(min(N,M))，但此处展示清晰的结构化逻辑
const findLCS = (s1, s2) => {
  const m = s1.length;
  const n = s2.length;
  // 初始化二维数组，边界条件隐含为 0
  const dp = Array(m + 1).fill(null).map(() => Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      // 核心判断：当前字符是否一致
      if (s1[i - 1] === s2[j - 1]) {
        // 匹配成功：对角线左上角值 + 1
        dp[i][j] = dp[i - 1][j - 1] + 1;
      } else {
        // 匹配失败：取上方或左方的最大值，体现最优子结构
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }
  // dp[m][n] 即为最终结果
  return dp[m][n];
};
```

### 4. 常见误区与进阶思考
1. 混淆“子序列”与“子串”的状态重置规则：这是最常见的认知误区。在子串问题中，一旦字符不匹配，必须强制将当前状态置为 0，因为子串要求连续性；而在子序列中，不匹配时只需继承历史最优值（来自上方或左方），无需重置。工程开发中若搞错此逻辑，会导致结果严重偏差。

2. 忽略空间复杂度优化：对于极长文本，O(M*N) 的空间占用可能导致内存溢出。进阶思考应意识到，计算 dp[i] 行仅依赖于 dp[i-1] 行及更早的数据，因此可使用滚动数组或双指针技巧将空间降至 O(min(M,N))。

深度思考题：如果不仅要计算最长公共子序列的长度，还需要回溯并输出具体的子序列字符串，你应该如何在 DP 表的基础上设计回溯算法？如果需要支持任意编辑距离（包括插入、删除、替换），该状态转移方程需要做怎样的扩展？
