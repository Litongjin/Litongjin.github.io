# 每日基础技术总结 · 2026-06-25 · 树状数组 lowbit 与区间和/差分

## 📚 今日主题

> **树状数组 lowbit 与区间和/差分**（算法与数据结构）

### 1. 核心概念速览
树状数组（Fenwick Tree）是一种支持单点更新与前缀和查询的线性数据结构，其核心是 lowbit 运算：lowbit(x) = x & (-x)，表示 x 的二进制表示中最低位的 1 所对应的权值。它维护的是一个隐式的部分和数组，使得每个元素只负责一段长度为 lowbit(i) 的区间和，从而将前缀和操作的时间复杂度降为 O(log n)。本质上是将整数下标按二进制低位进行层次化分解，利用二进制的幂次间隔实现信息的压缩存储。树状数组解决的核心问题是：在数组元素频繁修改的情况下，快速计算前缀和或区间和，其机制是通过下标二进制中最低位 1 的进位和退位来实现更新与查询的跳跃。在整个计算机体系中，它属于基础算法与数据结构范畴，是理解更复杂数据结构（如线段树、可持久化树状数组、CDQ 分治）的基石。专业工程师必须掌握它，因为它在实际系统中常用于维护动态前缀统计、逆序对、差分区间更新等场景，且实现极简、常数极小，是性能敏感型服务中的常用工具。

### 2. 底层原理剖析
树状数组的底层原理基于二进制索引。定义数组 c[i] 表示原数组 a 中区间 (i - lowbit(i), i] 的和，即 c[i] = a[i-lowbit(i)+1] + ... + a[i]。lowbit(x) = x & (-x) 利用了补码性质：-x 等于 x 按位取反加一，因此 x & (-x) 恰好提取出最低位的 1。查询前缀和 sum(x) 时，从 i=x 开始，不断累加 c[i] 并令 i -= lowbit(i)，直到 i=0。这相当于将 x 的二进制表示中的每个 1 位对应的区间和相加。例如 x=13（1101），lowbit 依次为 1, 4, 8，对应区间 (12,13], (8,12], (0,8]，恰好覆盖 [1,13]。更新操作 add(idx, delta) 时，从 i=idx 开始，不断执行 c[i] += delta 并令 i += lowbit(i)，直到 i>n。因为包含 a[idx] 的所有 c[i] 的下标 i 恰好是 idx 加上其 lowbit 后的序列，即 idx, idx+lowbit(idx), ...，这等价于二进制进位过程。区间和 [l,r] 等于 sum(r) - sum(l-1)。差分扩展：若用树状数组维护差分数组 d[i]=a[i]-a[i-1]，则单点查询 a[k] 等于 d 的前缀和 sum(k)，区间更新 [l,r] 加 v 等价于 d[l]+=v, d[r+1]-=v。这种结构本质上是对前缀和的可持久化增量操作，相比前缀和数组 O(1) 查询但 O(n) 更新，树状数组将两者平衡在 O(log n)。与前端概念对比：类似 TypeScript 的接口与 Java 的接口——TS 接口是结构化类型（鸭子类型），Java 接口是显式契约；树状数组的 lowbit 与线段树的二分划分都是将区间问题归约为二进制/幂次结构，但树状数组只能处理可减操作（如和、异或），不能处理不可减操作（如最大值），而线段树可以。这正是两者本质区别：树状数组依赖逆运算，线段树不依赖。

### 3. 基础代码与实战验证
```text
// 极简树状数组实现（1-based 索引）
class Fenwick {
  constructor(n) {
    this.n = n;
    this.c = new Array(n + 1).fill(0);
  }
  // lowbit: 提取最低位 1 对应的权值
  lowbit(x) {
    return x & (-x);
  }
  // 单点更新：将 a[idx] 增加 delta
  add(idx, delta) {
    // 从 idx 开始，每次加上 lowbit，覆盖所有包含 idx 的区间
    // 例如 idx=3(011)，lowbit=1 -> 4(100) -> 8(1000)，c[4]和c[8]都包含a[3]
    for (let i = idx; i <= this.n; i += this.lowbit(i)) {
      this.c[i] += delta;
    }
  }
  // 前缀和：计算 [1, idx] 的和
  sum(idx) {
    let res = 0;
    // 从 idx 开始，每次减去 lowbit，拆分成不重叠的区间
    // 例如 idx=13(1101)，依次累加 c[13] (12,13], c[12] (8,12], c[8] (0,8]
    for (let i = idx; i > 0; i -= this.lowbit(i)) {
      res += this.c[i];
    }
    return res;
  }
  // 区间和 [l, r]
  rangeSum(l, r) {
    return this.sum(r) - this.sum(l - 1);
  }
}
// 差分用法：维护差分数组，支持区间更新和单点查询
const fw = new Fenwick(n);
// 区间 [l, r] 加 v
fw.add(l, v);
if (r + 1 <= n) fw.add(r + 1, -v);
// 单点查询 a[k]
const val = fw.sum(k);
```

### 4. 常见误区与进阶思考
误区一：认为树状数组可以像线段树一样直接维护任意区间最值。实际上树状数组的查询依赖前缀和的可减性（即逆运算），区间和可以通过 sum(r)-sum(l-1) 得到，但 max/min 没有逆运算，因此不能直接用标准树状数组求区间最大值。如果要维护最值，需要改造树状数组的查询逻辑（如单点更新且不支持区间最值查询的退化情况），或改用线段树。
误区二：lowbit 误以为是对 i 的二进制位数取反再减，或写成 i & (-i) 与 i - (i & (i-1)) 混淆。本质是补码取最低位 1，必须理解 x & (-x) 的位运算机制，否则在负数或有符号整数上容易出错（实际上在无符号整数也正确，但思维上要清晰）。
进阶思考题：为什么树状数组的更新操作是 i += lowbit(i)，而查询是 i -= lowbit(i)？请用二进制进位的角度解释这两个方向互为逆过程，并说明如果采用 i += lowbit(i) 从 1 开始构建，但查询方向改为 i += lowbit(i) 会破坏什么性质？请具体推演一个例子（如 n=8，索引 3 的更新路径和索引 7 的查询路径）来验证其覆盖关系。
