# 每日基础技术总结 · 2024-06-12 · 浏览器图层与合成器的工作机制

## 📚 今日主题

> **浏览器图层与合成器的工作机制**（前端底层与计算机基础）

### 1. 核心概念速览
浏览器渲染引擎将 DOM 树转换为 Render Object 树后，并非直接绘制像素，而是将其划分为多个独立层（Layer）。每个层包含自己的几何信息（Transform）和内容资源。合成器线程（Compositor Thread，通常位于 GPU 进程）根据层的层级关系、可见性、重叠度等约束条件，生成 Display List 并指令 GPU 执行合成操作。该机制的核心目的是实现 GPU 加速的离屏渲染与页面重绘，解决主线程阻塞导致的帧率抖动问题。在 AI/计算机体系中，这与现代图形 API（OpenGL/Vulkan/Metal）中的图层混合（Blending）和命令缓冲区（Command Buffer）机制同源，理解它是掌握 WebGL/WebGPU 底层渲染管线及高分辨率 UI 渲染优化的基石。
