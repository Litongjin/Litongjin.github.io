# 每日基础技术总结 · 2026-06-26 · 0/1 背包的一维 DP 与逆序更新

## 📚 今日主题

> **0/1 背包的一维 DP 与逆序更新**（算法与数据结构）

### 1. 核心概念速览
0/1 背包问题：给定 n 个物品，每个物品重量 w[i]、价值 v[i]，背包容量 W，每件物品最多选一次，求装入背包的最大价值。其状态转移本质是离散组合优化中的子集选择问题，属于 0-1 整数规划的特例。一维 DP 是通过滚动数组将二维 DP 的状态压缩到一维，核心机制是「逆序更新」以保证每个物品只被使用一次。逆序更新的本质是：在容量维度上从大到小遍历时，当前状态 f[j] 的更新所引用的 f[j-w[i]] 尚未被当前物品污染，因此它仍是上一轮（未考虑当前物品）的最优解；而正序更新时 f[j-w[i]] 已被本轮更新，等价于物品可无限取用，退化为完全背包。在计算机科学体系中，该问题是动态规划思想的经典入门模型，也是理解状态压缩、依赖顺序、无后效性的基石；在 AI 中，它广泛用于资源分配、模型剪枝中的子集选择、以及组合优化问题的近似求解。专业工程师必须掌握，因为它训练了对状态维度和更新顺序的敏感度，是编写正确高效动态规划算法的基础能力。

### 2. 底层原理剖析
设 f[j] 表示容量为 j 时能获得的最大价值。二维状态转移为：f[i][j] = max(f[i-1][j], f[i-1][j-w[i]] + v[i])，其中 i 表示前 i 个物品。观察发现第 i 层只依赖第 i-1 层，因此可用一维数组 f[j] 滚动存储。关键点在于更新顺序：

for i = 1..n:
    for j = W..w[i]:
        f[j] = max(f[j], f[j - w[i]] + v[i])

逆序（j 从 W 向下到 w[i]）保证在计算 f[j] 时，f[j - w[i]] 仍然是上一轮 i-1 的结果。因为 j - w[i] < j，逆序时 j 递减，所以 j - w[i] 尚未被当前轮更新；正序时 j 递增，j - w[i] 已被当前轮更新，相当于 f[i][j-w[i]]，即允许重复选择当前物品，因此正序适用于完全背包。

与前端知识的对比：类似 JavaScript 闭包捕获循环变量时用 let 与 var 的区别——逆序/正序决定了每次迭代读取的是「旧值」还是「新值」。闭包问题中，var 导致所有回调共享同一变量（正序的“污染”），let 为每次循环创建新绑定（逆序的“隔离”）。这里逆序更新正是为了隔离当前物品对更小容量的影响。更本质地，可类比 React 状态更新中的函数式更新：setState(prev => ...) 中 prev 一定是上次提交的值，而直接依赖外部变量可能读到旧值。但本质上，这是「时间维度」在空间上的压缩：一维数组同时存储不同 i 的历史版本，逆序访问保证读取的是旧版本。

伪代码：
输入：w[], v[], 容量 W, 物品数 n
初始化 f[0..W] = 0
for i from 1 to n:
    for j from W down to w[i]:
        f[j] = max(f[j], f[j - w[i]] + v[i])
输出 f[W]

### 3. 基础代码与实战验证
```text
function knapsack01(weights, values, W) {
    // f[j] 表示容量为 j 时的最大价值，初始为 0
    const f = new Array(W + 1).fill(0);

    // 遍历每个物品，每个物品只能选一次
    for (let i = 0; i < weights.length; i++) {
        const w = weights[i];
        const v = values[i];

        // 关键：逆序遍历容量，从大到小，确保 f[j-w] 是上一轮（未包含当前物品）的结果
        for (let j = W; j >= w; j--) {
            // 状态转移：不选当前物品保持 f[j]，选则加上当前价值，取较大者
            f[j] = Math.max(f[j], f[j - w] + v);
        }
    }

    return f[W];
}

// 验证：重量 [2,3,4,5]，价值 [3,4,5,6]，容量 5，期望最大价值 7（选物品1和2）
console.log(knapsack01([2,3,4,5], [3,4,5,6], 5)); // 输出 7

// 若改成正序 for (let j = w; j <= W; j++)，则同一物品可被重复选取，输出 10（选两个重量2的物品），这验证了逆序的必要性
```

### 4. 常见误区与进阶思考
误区1：认为一维 DP 只是二维 DP 的「空间优化」，而忽略了逆序更新的时间语义。实际上，逆序不是简单的空间技巧，而是通过遍历方向强制实现了「每件物品只能使用一次」的约束，顺序一旦颠倒，问题就变成了完全背包，结果完全不同。专业工程师可能凭记忆写出逆序，但不理解为何，导致在变种问题（如恰好装满、求方案数）中无法正确调整初始化或遍历方向。

误区2：混淆「状态压缩」与「无后效性」。一维 DP 成立的前提是状态转移只依赖上一层且满足无后效性，但逆序更新本身也利用了「当前物品在更小容量上的新状态不应被更大容量引用」这一逻辑。若忽略容量与物品重量的边界条件（如 w[i]=0），逆序会退化为完全背包，需要特殊处理。

思考题：若将问题改为「背包必须恰好装满」，初始化时 f[0]=0，其余 f[j]=-∞，然后仍用逆序更新，为什么？请结合一维 DP 的滚动数组本质解释 -∞ 的作用，以及为什么正序在这里同样会导致错误。
