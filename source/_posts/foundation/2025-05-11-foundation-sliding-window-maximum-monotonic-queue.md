# 每日基础技术总结 · 2025-05-11 · 滑动窗口最大值与单调队列

## 📚 今日主题

> **滑动窗口最大值与单调队列**（算法与数据结构）

### 1. 核心概念速览
滑动窗口最大值是一个在固定或动态大小窗口内求极值的问题，单调队列（Monotonic Queue）是其最优解法的数据结构本质。该问题核心在于维护一个下标递增且对应元素值单调递减的双端队列，从而保证队首始终为当前窗口的最大值。在计算机体系中，它是时间复杂度优化从 O(N*W) 降至 O(N) 的经典案例，体现了空间换时间与状态剪枝的思想。对于后端高并发日志处理、AI 中的实时信号滤波及资源监控，理解其 O(1) 均摊复杂度的机制至关重要，避免低效的重复计算。

principals": "底层运行机制依赖于双端队列（Deque）维护潜在最大值的序列。当新元素进入窗口时：1. 弹出队尾所有小于新元素的索引（因为它们在新元素存活期间永远不会成为最大值，被‘遮蔽’）；2. 将新元素索引加入队尾；3. 若队首索引滑出窗口范围，则移除队首。这一过程确保了队列严格单调递减。对比前端/TS概念：这类似于 React 的 Fiber 链表或 Vue 的依赖追踪树，但更强调‘淘汰机制’——只有更具‘竞争力’（更大）的元素才能保留在候选集中。与 Java Interface（静态契约）不同，单调队列是一种运行时动态的状态容器，其结构随数据流实时重构，而非编译期确定的类型定义。它本质上是对区间最值问题的线性扫描优化，利用了‘后入者胜出’的局部有序性。

code": "def maxSlidingWindow(nums, k):\n    from collections import deque\n    dq = deque() # 存储索引，非数值\n    result = []\n    for i in range(len(nums)):\n        # 1. 维护单调性：移除比当前数小的队尾元素\n        while dq and nums[dq[-1]] <= nums[i]:\n            dq.pop()\n        # 2. 添加当前索引\n        dq.append(i)\n        # 3. 移除超出窗口范围的队首元素\n        if dq[0] == i - k:\n            dq.popleft()\n        # 4. 窗口形成后记录结果\n        if i >= k - 1:\n            result.append(nums[dq[0]])\n    return result\n# 注释说明: dq[0] 即为当前窗口最大值索引。pop/popleft 操作确保每个元素最多进队一次、出队一次，故总复杂度 O(N)。\n

"pitfalls": "误区一：混淆存储对象。初学者常直接在队列中存储数值，导致无法判断元素是否已滑出窗口边界（需同时存储索引）。误区二：误解单调方向。求解最小值时需用单调递增队列，求解最大值用单调递减队列，方向错误会导致逻辑崩塌。思考题：如果窗口不是固定的整数大小，而是基于时间戳的动态区间（如过去5秒内的最大CPU使用率），单调队列策略需要做何种根本性调整？提示：考虑失效条件的变化对 pop 操作的影响。
