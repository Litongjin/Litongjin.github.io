🚀 技能提升点（工作总结汇总）

1. Quill 内容同步用 getHTML 而非 getContents

  • 技能点：掌握 vue-quill 中 Delta 与 HTML 的区别，正确同步编辑器内容到 v-model。
  • 坑点：getContents() 返回 Delta 对象，被当 HTML 字符串传给 DOMParser 后污染 modelValue，导致替换/匹配全失败。
  • 解决方案：改用 quillRef.value?.getHTML?.() ?? ‘’ 取真实 innerHTML 后再处理。
  • 拓展：任何 Quill 内容读取/回显都应优先 getHTML 或 root.innerHTML，避免 Delta JSON 串。
  • 来源：admin-workspace（QuillEditor）

2. HTML 实体整体解码与区间映射

  • 技能点：掌握 HTML 实体解码的正确姿势，并能维护实体到原文的区间映射。
  • 坑点：逐字符解码多字符实体（如 <）会失败或拆开实体，导致匹配/高亮错乱。
  • 解决方案：文本节点累积后整体 decodeHtmlEntities，mapIndex 映射到实体起始偏移，命中实体时边界延伸到实体末尾。
  • 拓展：可用于任何把 HTML 拍平为纯文本并保持位置映射的场景（高亮、替换、diff）。
  • 来源：admin-workspace（questionCheck.ts）

3. HTML 标签解析需引号感知

  • 技能点：编写健壮的 HTML 标签扫描逻辑，属性值内含 >/< 时不截断标签。
  • 坑点：用 indexOf(‘>’) 定位标签结束，遇到 data-formula 值内原始 > 会拦腰截断，导致内容丢失。
  • 解决方案：扫描时进入引号内跳过，直到引号外遇到真正的 > 才视为标签结束。
  • 拓展：最好在生成 HTML 时将属性值中的特殊字符实体化，从源头规避。
  • 来源：admin-workspace（questionCheck.ts）

4. 文本匹配需容忍空白差异

  • 技能点：实现容空白的模糊匹配，用于 AI 生成内容与正文的比对。
  • 坑点：AI 生成的 latex 与正文 latex 空格不一致，严格字面匹配永远失配。
  • 解决方案：构建 buildWhitespaceTolerantRegex（字符间允许 \s*），严格匹配失败后再用容空白正则重试，并剔除首尾空白防越界。
  • 拓展：可推广到任何外部数据与本地文本的匹配，注意避免零宽匹配。
  • 来源：admin-workspace（questionCheck.ts）

5. Vue watch 双向同步需值比较守卫

  • 技能点：规避 Vue 中 watch 互相触发导致的无限递归。
  • 坑点：状态 A → 数组 → 状态 B → 状态 A 的同步链中，每次写新数组引用，即使值未变也触发 deep watch，最终报 Maximum recursive updates exceeded。
  • 解决方案：每次写回前先比较当前值与推导值，相等则 return，阻断循环。
  • 拓展：所有跨 ref 的 watch 同步都应做值守卫，避免无意义写引用。
  • 来源：admin-workspace（2026-08-11）

6. Element Plus 按需引入需显式 CSS

  • 技能点：理解 unplugin-vue-components + ElementPlusResolver 的按需注册局限，能定位 CSS 缺失问题。
  • 坑点：较新组件（el-splitter 等）的 CSS 不会被 resolver 自动补齐，导致布局/交互失效（面板堆叠、拖拽不可见）。
  • 解决方案：在组件中显式 import ‘element-plus/theme-chalk/el-splitter.css’ 等，不依赖全量 CSS。
  • 拓展：遇到组件样式异常时，优先检查对应 CSS 是否被按需引入。
  • 来源：admin-workspace（MEMORY.md）
