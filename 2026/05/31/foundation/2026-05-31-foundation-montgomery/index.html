📚 今日主题

椭圆曲线密码中的无效曲线攻击与 Montgomery 阶梯（安全基础）

1. 核心概念速览

无效曲线攻击（Invalid Curve Attack）的本质是：在椭圆曲线标量乘法实现中，若未验证输入点是否属于定义在特定域上的合法曲线，攻击者可以注入一个坐标满足某种运算规律但不在原曲线方程上的点，使标量乘法在另一个群（通常为具有小因子的弱群）中进行，从而通过错误结果或侧信道逐步还原私钥。Montgomery 阶梯是一种恒定时间（constant-time）的标量乘法算法，它基于 Montgomery 曲线形式，仅使用 x 和 z 坐标完成点乘运算，流程固定且不依赖私钥位分支，因此既抵抗时间侧信道，也能在运算中因坐标不满足曲线方程而输出无意义结果，从而阻断部分无效曲线攻击。该知识点属于公钥密码实现安全与侧信道防护的交叉领域，位于 ECC 工程实现的底层。专业工程师必须掌握，因为现代密码库（如 TLS、区块链钱包）的健壮性不仅依赖算法数学正确性，更依赖对异常输入和物理泄漏的防御，否则即使曲线本身安全，实现依然可被攻破。

2. 底层原理剖析

椭圆曲线上的点群运算规则（加法、倍点）在数学上依赖于曲线方程。对于 Weierstrass 形式 y² = x³ + ax + b，若一个点不在该曲线上，但代入群运算公式（仍使用原来的 a、b 参数），则运算结果不一定落在原曲线上；然而，这一组点集合配上同样的运算规则，可能构成一个新的群（即无效曲线群）。攻击者构造一个无效曲线，其阶 n’ 含有小因子，然后发送该曲线上的点 P’ 给受害者，受害者执行 Q = kP’（k 为私钥），由于 P’ 阶很小，结果 Q 的离散对数（即 k mod n’）可通过穷举或 Pohlig-Hellman 快速求解。多次使用不同小因子群，即可通过 CRT 重组完整私钥。

Montgomery 阶梯的核心机制是：Montgomery 曲线形式为 B y² = x³ + A x² + x，标量乘法仅需 x 坐标，使用射影坐标 (X:Z) 表示 x = X/Z。算法维护两个点 (R0, R1)，其中 R0 = mP，R1 = (m+1)P，按私钥位从高到低或从低到高遍历，每位执行统一的加法和倍点操作，不进行条件分支。其安全特性在于：1. 运算序列与私钥位无关，指令模式恒定；2. 它只计算 x 坐标，不计算 y，因此即使输入点不在曲线上，由于 Montgomery 阶梯中的倍点公式（例如 x_{2n} = (x_n² - 1)² / (4x_n(x_n² + A x_n + 1))）会依赖于曲线参数 A，若点不在曲线上，则运算结果不满足任何一致群律，最终输出混乱，不会泄露与私钥相关的有效离散对数信息。但注意，Montgomery 阶梯并非万能，若攻击者输入低阶点且该点在某个 Montgomery 型无效曲线上，仍可能产生可观测的差异（如结果等于无穷远点），因此实践中仍需显式验证点是否在合法曲线上。

与前端已有概念的对比：Java 的接口是运行时类型（JVM 中实际存在 Class 对象），TypeScript 的接口是编译期结构类型，编译后消失；类似地，椭圆曲线点验证是运行时强制约束，绝不能依赖编译期或类型系统保证。无效曲线攻击类似于前端原型链污染——输入对象未验证是否拥有合法原型链（即是否属于预期类），导致攻击者注入非法对象并篡改执行逻辑。Montgomery 阶梯则类似于前端恒定时间字符串比较（如 crypto.timingSafeEqual），通过消除可预测的分支时序来防止时序攻击，体现了安全实现必须从底层数据流与执行流出发，而非依赖表面 API。

4. 常见误区与进阶思考

误区一：认为使用 Montgomery 阶梯就可以忽略输入点验证。实际上，Montgomery 阶梯只是恒定时间执行，它不能保证输入点属于合法曲线。对于某些无效曲线，如果攻击者构造的点的 x 坐标满足 xDBL 和 xADD 公式的封闭性，则运算仍会在一个弱群中进行，且因为算法不检查 y，私钥信息依然可能通过结果或错误行为泄露（例如输出无穷远点导致可观察差异）。X25519 之所以安全，是因为它额外采用了曲线上所有点的阶都带有 cofactor 8（或 4）的设计，并配合私钥 clamping，使得低阶点只能泄露私钥的少数低比特位，而这部分已被预置为固定值。绝不能将 Montgomery 阶梯视为通用的点验证替代品。

误区二：认为无效曲线攻击只影响 Weierstrass 曲线，Montgomery 曲线天然免疫。实际上，Montgomery 曲线的方程形式 B y² = x³ + A x² + x 同样存在无效曲线，攻击者可选取不同 B’ 或 A’ 构造具有小阶的点，只要 x 坐标满足某个关系。Montgomery 阶梯仅使用 x 坐标，反而为攻击者提供了更大的自由度（不必提供 y 坐标），因此实现时必须依赖域上的约束、cofactor 清除或显式验证。

思考题：假设一条 Montgomery 曲线上有一个阶为 2 的点 P（即 2P = 无穷远点），其 x 坐标为 0 或某个特定值。如果攻击者向使用 Montgomery 阶梯的服务器发送这个 x 坐标，且服务器不验证点的阶，私钥 k 是什么值时输出无穷远点？这个输出能否被攻击者利用来推断 k 的奇偶性？请从阶梯运算的初始化与最终 R0 的表达式推导，并说明如何通过设计私钥 clamping 来消除这种泄漏。
