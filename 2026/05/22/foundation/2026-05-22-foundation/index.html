向量相似度度量选择：余弦、欧氏与内积的关系（AI 开发基础）

1. 核心概念速览

向量相似度度量本质上是定义在向量空间上的一个二元函数，用于量化两个向量在几何或代数意义上的接近程度。余弦相似度度量的是两个向量在方向上的一致性，其定义是向量内积除以模长之积，即 cos(θ) = <a,b>/(|a||b|)，取值在[-1,1]，与向量长度无关。欧氏距离度量的是向量在空间中的直线距离，即 L2 范数差，取值非负，同时受方向与长度影响。内积（点积）本身不是一种独立的’相似度’，它是更底层的双线性运算，直接反映向量在某一方向上的投影乘积之和。三者本质关系：内积是余弦相似度的未归一化形式；若向量已归一化（模长为1），内积与余弦完全等价；欧氏距离的平方与内积满足 |a-b|² = |a|² + |b|² - 2<a,b>，在固定模长条件下，欧氏距离与余弦呈单调负相关。该知识点处于向量检索、嵌入表示、推荐系统和机器学习特征工程的交叉位置，是理解向量数据库、语义搜索、聚类算法的基础。专业工程师必须掌握，因为实际系统（如 FAISS、Milvus、pgvector）的索引类型（IVF、HNSW）默认度量选择直接影响召回率和检索效率，选错度量会导致结果语义偏离。

2. 底层原理剖析

底层机制可从线性代数与几何两个视角剖析。设 a=(x1,…,xn), b=(y1,…,yn)。内积 <a,b> = Σ xiyi，本质是将 b 投影到 a 的方向后与 a 的模长相乘，结果受向量长度影响。余弦相似度 = <a,b>/(||a||·||b||)，它首先对向量做 L2 归一化（除以各自模长），再进行内积，因此消除了长度变量，只保留方向夹角信息。欧氏距离 d = sqrt(Σ(xi-yi)²)，其平方展开为 ||a||² + ||b||² - 2<a,b>。当 ||a||=||b||=1 时，d² = 2-2cos(θ)，所以欧氏距离与余弦相似度一一对应：距离越小，余弦越大。在未归一化场景，三者差异显著：两个方向相同但长度相差很大的向量，余弦为1，欧氏距离却很大；两个长度相近但方向相反的向量，余弦为-1，欧氏距离可能很小（若长度接近0）。实际系统（如向量数据库）通常提供’内积’选项，此时若直接对未归一化向量使用内积，长度偏大的向量会占据主导，这等价于隐含了’长度代表重要度’的先验假设；而使用余弦则必须先对向量做归一化，或者数据库内部自动归一化后再计算内积。从计算复杂度看，内积运算量为 O(n)，余弦需额外计算两个模长（同样 O(n)），欧氏距离需计算差向量模长（O(n)）。在工程实现上，若已离线归一化，在线推理时余弦和欧氏都可退化为纯内积或内积的线性变换，因此 FAISS 中 ‘METRIC_INNER_PRODUCT’ 与 ‘METRIC_L2’ 可以互相转换：先归一化所有向量，则内积排序等价于余弦排序；L2 排序等价于 2-2内积 排序。这个关系类似于前端中 Java 接口与 TypeScript 接口的本质差异：Java 接口是编译期类型契约 + 运行期多态分发机制，TS 接口是纯编译期结构化类型约束，运行时不存留。它们有相似的名词，但底层存在性完全不同。同理，内积、余弦、欧氏在数学定义上紧密关联，但作为度量函数时各自的语义边界和适用场景不同，不能仅凭名称或公式混用。

4. 常见误区与进阶思考

误区1：认为余弦相似度一定优于欧氏距离，或反之。实际上二者在不同归一化条件下可互相转化。在向量已归一化时，排序结果完全等价。真正的差异在于向量长度是否携带业务语义。例如在 TF-IDF 或词袋向量中，文档长度包含信息，但余弦通过归一化消除了文档长度差异，只关注词的相对分布；而欧氏距离保留长度，适合向量长度本身有意义的场景（如用户活跃度向量）。工程师应依据特征是否应受模长影响来选度量，而不是凭习惯。

误区2：直接对未归一化向量使用内积当作余弦相似度。许多向量数据库默认提供内积度量，若直接传入原始嵌入向量（如 OpenAI 的 text-embedding-ada-002，默认已归一化则无碍，但很多开源模型输出未归一化），内积结果会被向量模长主导，导致长向量永远排在前。正确做法是：在使用内积作为余弦替代前，必须先对向量做 L2 归一化；反之若使用欧氏距离作为余弦替代，需要先归一化并做单调变换。

思考题：给定向量集合，其中每个向量的模长各不相同。假设业务中’向量方向’代表语义类别，’向量模长’代表置信度（模长越大越可信）。现在要检索与查询向量语义最相似且置信度不低于查询向量的结果，应选择哪种度量？如果改用余弦或欧氏距离，分别会丢失什么信息？请从数学表达式出发推导检索结果的排序差异，并说明如何通过组合或加权方式同时保留方向与模长信息。
